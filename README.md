# Dashboard de Vendas Xbox com Excel

## Sobre o projeto

Este projeto tem como objetivo desenvolver um dashboard de vendas no Microsoft Excel, utilizando recursos de organização, tratamento e visualização de dados para transformar informações brutas em indicadores visuais que facilitem a análise de desempenho comercial.

A proposta faz parte de um desafio prático da DIO e busca aplicar os conhecimentos adquiridos em Excel na construção de uma ferramenta visual para análise de dados e apoio à tomada de decisões.

O dashboard será desenvolvido a partir da base de dados disponibilizada no desafio, com foco na organização das informações, na apresentação dos resultados e na facilidade de interpretação dos indicadores.

## Objetivos

- Organizar os dados utilizados na análise de vendas.
- Transformar dados brutos em informações visuais.
- Desenvolver indicadores que auxiliem na compreensão do desempenho comercial.
- Construir gráficos e elementos visuais para facilitar a interpretação dos resultados.
- Estruturar um dashboard com uma apresentação clara e organizada.
- Documentar o processo de desenvolvimento e os recursos utilizados no Excel.

## Dados utilizados

O desafio disponibiliza os seguintes materiais de apoio:

- **Base de Dados — `base.xlsx`:** arquivo de referência para a construção do dashboard.
- **Dashboard Finalizado — `dashboard_xbox_finalizado.xlsx`:** arquivo de referência visual para compreender a proposta e comparar a estrutura da solução desenvolvida.

A análise será baseada nos campos efetivamente disponíveis na base de dados. Os indicadores, filtros e gráficos apresentados na versão final serão documentados conforme a implementação realizada no Excel.

## Ferramentas e recursos

- Microsoft Excel.
- Organização e estruturação de dados.
- Fórmulas e funções do Excel, conforme a necessidade da análise.
- Gráficos e indicadores visuais.
- Recursos de formatação e organização de dashboards.
- GitHub para versionamento e documentação do projeto.

## Desenvolvimento do projeto

O desenvolvimento será realizado a partir das seguintes etapas:

1. **Exploração dos dados:** compreender a estrutura da base e identificar as informações disponíveis.
2. **Preparação dos dados:** organizar os campos necessários para as análises.
3. **Definição dos indicadores:** selecionar métricas relevantes de acordo com as informações existentes.
4. **Construção do dashboard:** desenvolver os gráficos, indicadores e elementos visuais no Excel.
5. **Validação:** conferir os resultados apresentados e verificar se os elementos visuais correspondem aos dados de origem.
6. **Documentação:** registrar as funcionalidades implementadas e disponibilizar o arquivo final neste repositório.

## Como reproduzir

Após a conclusão do projeto:

1. Baixe ou clone este repositório.
2. Abra a base de dados disponibilizada no desafio.
3. Abra o arquivo Excel do dashboard.
4. Confira a organização dos dados, os indicadores e os gráficos.
5. Explore os resultados apresentados para compreender as análises realizadas.

Os arquivos necessários e as instruções específicas serão atualizados conforme a versão final do projeto.

## Resultados esperados

A entrega busca demonstrar a aplicação prática do Excel na organização e visualização de dados comerciais, reunindo indicadores e gráficos em uma interface que facilite a compreensão das informações.

O dashboard final será disponibilizado neste repositório após a conclusão da etapa prática.

## Aprendizados

O projeto tem como foco desenvolver habilidades de análise e visualização de dados, organização de informações, elaboração de dashboards e documentação técnica.

Além da construção da ferramenta, a proposta permite praticar a transformação de dados em informações úteis para apoiar a análise de resultados e a tomada de decisões.
